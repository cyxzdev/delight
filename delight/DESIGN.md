# Delight design (on top of Fluxer's web app)

Goal: same functionality as Fluxer, but it must look and feel like a different product: our palette, our type, flatter
and more compact, and a few deliberate placement changes. Never remove features; restyle and rearrange.

## Palette (already wired through Fluxer's tokens in `fluxer_app/scripts/GenerateColorSystem.ts`)
Use Fluxer's existing CSS variables, never hard-coded hex values, so the theme stays consistent:
- Surfaces (darkest → lightest): `--background-primary` (~#0d0d0d), `--background-secondary`,
  `--background-secondary-alt`, `--background-tertiary`, `--background-header-primary`. The main chat area must read as
  #141414-ish, sidebars a step darker, popovers/modals a step lighter.
- Text: `--text-primary` (≈#e6e6e6), `--text-chat` (≈#cfcfcf), `--text-secondary`, `--text-primary-muted`,
  `--text-tertiary`.
- Accent: `--brand-primary` (#7F49B4), `--brand-secondary` (hover). Hairlines: `--background-modifier-accent`.
  Hover/selected fills: `--background-modifier-hover`, `--background-modifier-selected`.
- Purple only for: the one primary action in a view, selection indicators, mentions, focus rings, on-toggles,
  links-as-actions. Never large purple areas, never purple gradients. Unread/mention badges stay red.
- No gradients, glows, glassy blur, coloured shadows. Floating layers get one dark shadow plus a 1px hairline border.

## Type and shape
- Inter is global (`--font-sans`). Weights 400/500/600. Small headings: page titles 18–20px, modal titles 18px.
  Sentence case (tiny uppercase section labels 11px with 0.04em tracking are fine).
- Radii are already reduced globally (`--radius-sm` 3px … `--radius-2xl` 10px). Don't add pill shapes except
  avatars, status dots, toggles and badges.
- Compact: list rows 32px, member rows 40px, buttons 32px (small 28px), inputs 36px, headers 48px.
- Motion: 120ms colour/opacity transitions; floating layers fade + 4px lift in ≤150ms. No bounces or springs.

## Layout
Use the base app's own layout, sizes, spacing and corners (the user prefers its compact proportions). Delight changes
are colour (GenerateColorSystem.ts), the Inter font, branding, and the 32px title strip above the app
(WindowTitleStrip). Don't enlarge text, rows or padding, and don't add custom radii.

## Rules for agents
- Edit only your scope (given in your prompt). CSS modules first; change TSX markup only where placement changes need it.
  Keep props, exports, behaviour and accessibility intact.
- Don't edit: `scripts/GenerateColorSystem.ts`, `src/app/delight/delight.css`, `src/app/globals.css`,
  `src/index.tsx`, generated files (`*.module.css.d.ts` are regenerated by the build; `styles/generated/*`).
  Need a global change? Put it in your final report.
- Build + deploy: `~/delight-fluxer/delight/build.sh` (serialized with a lock; ~20–60s; prints errors on failure).
- Screenshots: `cd ~/delight-fluxer && SHOT_PORT=<your port> bun delight/shot.ts login` once, then
  `SHOT_PORT=<port> bun delight/shot.ts png <path> /tmp/<name>.png --wait 6000 [--eval "<js>"]`. Paths:
  `/channels/@me` (DMs/friends), `/channels/1556291570288820224/1556291570288820253` (Delight #general),
  `/login`, `/register` (use a logged-out port for those: run png without login on a fresh port).
- Never touch the user's own browser. Don't delete the Delight server, its channels or roles. Test messages are fine in
  #off-topic only; delete them afterwards.
